# Week 04 Report — Machine Learning for Smart and Connected Systems (ML4SCS)

## Weekly Goal
Record real sensor data for digit "3", set up preprocessing pipeline on real data, and prepare for multi-class training.

## Work Done This Week

### 1. Data Work
Recorded 10 real sensor recordings of digit "3" using Phyphox on smartphone.
Data collected with Accelerometer (without gravity) and Gyroscope simultaneously.
Data structure: `Time (s), Acceleration x/y/z (m/s^2)` and `Time (s), Gyroscope x/y/z (rad/s)`.
Recordings exported as ZIP files, unpacked and organized into `real_data/digit_3_run01` to `digit_3_run10`.

Also conducted a signal processing experiment comparing Butterworth lowpass filter at different cutoff frequencies (1 Hz, 5 Hz, 15 Hz) on walking vs. jogging data — confirmed that lower cutoff frequencies produce smoother signals and that jogging produces significantly larger acceleration amplitudes (±60 m/s²) compared to walking (±15 m/s²).

## Key Insights
- Real sensor data works well with the existing pipeline — no major adjustments needed
- Butterworth filter at 1 Hz is too aggressive for gesture recognition — 5 Hz is a better baseline
- Statistical features (mean, std, max, min) are sufficient as a baseline but may miss temporal patterns
